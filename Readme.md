# University & Personal Mini Projects

This repository contains **mini projects developed during university courses and personal experimentation**,  
covering topics such as algorithms, artificial intelligence, logic programming, functional programming, and software tools.

---

## Projects Overview

| # | Project | Description | Notes |
|---|---------|-------------|-------|
| ● | 8-Puzzle Solver — Java Command-Line App | Developed a command-line Java application for solving the classic 8-puzzle problem using Uniform Cost Search (UCS) and A* Search algorithms, alongside a manual play mode for user interaction and comparison of solving strategies. | See [folder](Eight_Puzzle_Solver) for full code and execution examples |
| ● | Haskell Exercises | Collection of educational Haskell exercises and functional programming implementations focused on learning core concepts and problem-solving techniques. | See [folder](Haskell_Mini_Projects) for full code examples |
| ● | Robots Collision Detection in Prolog | Implemented a Prolog simulation where two robots move on a grid following predefined paths, with logic to determine whether collisions occur during execution. | See [folder](Robot_Collider_Prolog) for full code and examples |
| ● | Text Analyzer (Under Development) | Building a Java-based text analysis tool using a Trie (prefix tree) data structure for efficient word storage, frequency analysis, prefix searching, and wildcard pattern matching. | See [folder](Text_Analyzer) for current progress and source code |
| ● | YouTube Playlist MP3 Downloader | Created a Python GUI application that downloads high-quality MP3 audio tracks from YouTube playlists using `yt-dlp` and `tkinter`. | See [folder](YoutubeToMP3Downloader) for full code and usage instructions |
